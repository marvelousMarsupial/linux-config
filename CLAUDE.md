# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Overview

Linux dotfiles and workstation provisioning using Ansible. Four roles with inheritance:

```
server          → base CLI workstation
dev-server      → server + development tools (code-server, jupyter, lazygit)
desktop         → server + Sway GUI
remote-desktop  → desktop + VNC
```

## Commands

### Deploy
```bash
# Install a role
./deploy/install.sh server        # or: dev-server, desktop, remote-desktop

# Or manually
ansible-playbook -i ansible/inventory.yml ansible/playbook.yml -e "role=desktop"
```

### Theme Switcher
```bash
theme list                    # List schemes (* = current)
theme apply gruvbox-dark-hard # Apply scheme
theme current                 # Show current
theme preview kanagawa        # Preview without applying
```

Schemes: `gruvbox-dark-hard`, `catppuccin-mocha`, `summerfruit-dark`, `summerfruit-light`, `ayu-light`, `kanagawa`

## Architecture

### Roles
- `ansible/roles/server/` - Base: zsh, tmux, neovim, yazi, starship, theme
- `ansible/roles/dev-server/` - Adds: build tools, npm, code-server, jupyter, lazygit, gh
- `ansible/roles/desktop/` - Adds: sway, foot, fuzzel, mako, flatpaks
- `ansible/roles/remote-desktop/` - Adds: tigervnc

### Stow Packages
```
stow/
├── zsh/          # .zshrc, .zsh_aliases
├── tmux/         # .tmux.conf (generated by theme)
├── nvim/         # LazyVim customizations
├── yazi/         # File manager config
├── theme/        # Python theme switcher + schemes + templates
├── sway/         # Sway WM config (desktop)
├── foot/         # Terminal config (desktop)
├── fuzzel/       # Launcher config (desktop)
└── mako/         # Notifications config (desktop)
```

### Theme System
Python script using Jinja2 templates. Targets all write regardless of role (missing app hooks just warn).

- `config.toml` - targets with output paths and reload hooks
- `schemes/` - base16 YAML (base00-base0F)
- `templates/` - Jinja2 for each app

Server targets: tmux, neovim, yazi
Desktop targets: + foot, sway, mako, fuzzel

### Key Files
- `ansible/playbook.yml` - Main playbook, accepts `role` variable
- `ansible/group_vars/all.yml` - Default theme setting
- `deploy/install.sh` - One-liner deployment script
